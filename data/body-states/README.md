# Body-state profiles

These files are versioned overlays for compatible vascular graphs. Each file
contains its evidence, intended population and state, transformation factor,
and known limitations. The profiles themselves and their derived numerical
transformations are released under CC BY 4.0; cited articles retain their own
publication rights.

Do not interpret a profile name as proof of physiological validation. Read the
`validity` and `limitations` fields before use. M2.6 methodology is documented
in `docs/m2/BODY_STATE_PROFILES.md`.
