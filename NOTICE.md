# MEHLISSA notices

MEHLISSA was initiated at Universität zu Lübeck. Historical and later source
files also identify Technische Universität Berlin and individual authors or
contributors. The notices embedded in each source file are authoritative and
must be retained.

The MEHLISSA Next architecture is developed as a new implementation with the
historical versions used as scientific and technical references. Files that
incorporate or derive from legacy GPL code must be identified as
`GPL-2.0-only`; they are not converted to MPL merely by being moved into a Next
directory.

When citing MEHLISSA in scientific work, use the publications listed in the
repository `README.adoc` and cite the concrete software version, commit, model,
and dataset used for the experiment.
