# Time-Varying Receptor Binding (M5.3)

## Purpose

M5.3 adds a deterministic numerical receptor-binding model for prescribed
ligand concentration trajectories. It preserves the exact M5.1 constant-input
model as an independent reference and adds a second segment-wise analytical
pulse reference.

This increment answers a narrow question: given a known extracellular
concentration history, how do receptor occupancy, peak response, dissociation,
and first threshold-crossing time evolve?

## Contract and numerical method

The request declares:

- request, ligand, and compartment identities;
- observation duration and initial bound fraction; and
- a strictly increasing trajectory beginning at offset zero.

Concentration is piecewise constant and left-closed. For each segment, the
model solves

```text
df/dt = kon L(t) (1 - f) - koff f
```

with fixed-step classical fourth-order Runge-Kutta. Steps end exactly at every
trajectory knot. The profile also bounds the integration step count and rejects
a step that is too large for the declared binding-rate scale.

The response reports final and peak bound fractions, total/free/bound receptor
amounts, the first upward threshold crossing, integration-step count, and one
bounded state sample per completed step plus the initial state.

## Executable profile

```text
examples/cell-models/synthetic-time-varying-receptor-ligand-v1.json
data/schemas/time-varying-receptor-ligand-profile/1.0.0.schema.json
```

The synthetic model uses the M5.1 parameters:

| Parameter | Value |
|---|---:|
| association rate | `1000 m3/(mol s)` |
| dissociation rate | `0.1 s-1` |
| detection threshold | `0.5` |
| integration step | `0.05 s` |
| maximum integration steps | `10000` |

## Reference case A: constant analytical limit

A constant concentration of `0.0003 mol/m3` over ten seconds has the exact M5.1
solution:

| Output | Analytical value |
|---|---:|
| final and peak bound fraction | `0.7362632708334493` |
| first threshold crossing | `2.7465307216702746 s` |

The numerical result must agree within the declared tolerance. Separate runs
with `0.5 s`, `0.25 s`, and `0.125 s` steps must show decreasing final-state
error; the finest error must be less than one hundredth of the coarsest error.

## Reference case B: prescribed pulse

The pulse is:

| Interval | Ligand concentration |
|---|---:|
| `[0 s, 2 s)` | `0 mol/m3` |
| `[2 s, 7 s)` | `0.0003 mol/m3` |
| `[7 s, 12 s]` | `0 mol/m3` |

Applying the closed-form constant-segment solution successively gives:

| Output | Analytical value |
|---|---:|
| peak bound fraction at pulse withdrawal | `0.6484985375725405` |
| final bound fraction after dissociation | `0.39333424581655096` |
| first threshold crossing from experiment start | `4.746530721670274 s` |

This case verifies that a detection event remains recorded even when occupancy
later falls below the threshold.

## Acceptance and safeguards

Focused tests verify:

- strict schema and semantic profile validation;
- constant-input convergence to the independent M5.1 exact result;
- the complete pulse, withdrawal, and dissociation reference;
- exact final total/free/bound receptor balance;
- output starts at zero and ends at the requested observation time;
- no-signal exposure produces no detection;
- non-zero first knots, duplicate or unordered knots, unsafe rate-step products,
  exhausted step budgets, duplicate reference roles, and invalid metadata are
  rejected.

Run them after a Debug build:

```powershell
ctest --test-dir build/windows-msvc -C Debug --output-on-failure `
  -R "time-varying|RK4|ligand pulse|bounded-solver"
```

## Evidence and limitations

All biological-looking numbers are synthetic software-verification parameters.
The time-dependent input is prescribed, homogeneous, deterministic, and
non-consuming. It is not yet generated by a dynamic M4 tissue model. There is
no ligand balance, spatial transport, stochastic molecule count, receptor
turnover, internalization, intracellular signaling, persistent cell state,
population distribution, or biological calibration.

Passing the two references validates the declared ODE implementation and event
semantics only. It does not establish that the trajectory, kinetics, threshold,
or response predicts a real receptor, cell, disease, or patient.
